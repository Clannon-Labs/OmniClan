## Suspects after repeated attempts && Culprits
> These were found to be the actual culprits
1. Problem with duration parsing
  - File: OmniClan/backend/crates/media/src/workers/upload/states/processing/probe.rs: line 312 (modified)
2. ffmpeg getting invalid path while trying to extract audio
  - File: OmniClan/backend/crates/media/src/workers/upload/states/processing/processing.rs: line 53-74 (modified)
3. Concatenation of a whole path as the extension of another path 
  - File: OmniClan/backend/crates/media/src/workers/upload/states/ready/ready.rs: line 31-37 (modified)

2. Extracted filename properly before trying to finalize the paths and joined it.
3. Before writing manifest, checked if the path is directory, and joined a filename if it is, and if not, created a file inplace of that filename
